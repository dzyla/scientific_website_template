# SciLab

Minimal Hugo theme for a research-group website, developed for and alongside
[zylalab.org](https://zylalab.org).

Layout, styling and behaviour live here; everything site-specific (text,
images, menus, contact details) belongs in the parent repository. Templates in
the site's own `layouts/` directory override the ones here.

Do **not** add a `content/` directory or a `hugo.toml` to this theme — Hugo
merges both into the consuming site.

MIT licensed, see `LICENSE`. Bundled fonts are under the SIL OFL; see
`static/fonts/OFL.txt` in the site repository.
